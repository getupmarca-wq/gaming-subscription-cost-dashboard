
# Gaming Subscription Cost Dashboard

## Project Overview

This project is a financial dashboard developed using **LibreOffice Calc** to analyze and compare the costs of EA Play Pass and Minecraft Pass subscriptions over the course of a year.

The spreadsheet organizes subscription expenses into different payment periods — monthly, four-month, and annual — making it easier to understand the financial impact of each option and compare subscription costs over time.

The main goal of this project is to transform subscription cost data into a clear visual presentation that supports expense tracking, cost comparison, and personal budgeting.

## Key Features

- **Annual Cost Analysis:** Presents subscription expenses over a full year to provide an overview of total spending.
- **Monthly Cost Comparison:** Organizes monthly subscription costs to help evaluate recurring expenses.
- **Four-Month Period Analysis:** Groups costs into four-month periods to support comparisons across different parts of the year.
- **Subscription Comparison:** Allows users to compare EA Play Pass and Minecraft Pass expenses using a consistent structure.
- **Data Visualization:** Uses charts and visual indicators to make cost differences and spending patterns easier to understand.
- **Financial Organization:** Consolidates subscription information into a single spreadsheet, helping users review and manage gaming-related expenses.

## Tools and Technologies

- **LibreOffice Calc:** Spreadsheet development, data organization, calculations, tables, and charts.
- **Data Analysis:** Comparison of subscription costs across different time periods.
- **Data Visualization:** Visual presentation of financial information to improve readability and interpretation.

## Project Objectives

This project demonstrates how spreadsheet tools can be used to organize financial data, compare recurring expenses, and present information in a visual and accessible format.

It also represents a practical learning project focused on data organization, cost analysis, and dashboard development.

## How to Use

1. Download the spreadsheet from this repository.
2. Open the file using LibreOffice Calc or a compatible spreadsheet application.
3. Review the dashboard, charts, tables, and cost indicators.
4. Compare the monthly, four-month, and annual subscription expenses.
5. Use the presented information to better understand the costs associated with EA Play Pass and Minecraft Pass.
